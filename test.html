⚠️ 에러 처리

ℹ️ 아래 테스트는 에러 SVG를 표시합니다. 정상 작동입니다.

존재하지 않는 사용자

"User not found" 메시지를 SVG로 표시합니다.

?username=invalid-user-xyz123456789 테스트

빈 사용자명

사용자명이 없으면 에러 메시지가 표시됩니다.

?username= 테스트

⚡ 성능 & 보안

캐싱 테스트

첫 요청: 느림 (MISS), 두 번째: 빠름 (HIT)

# curl로 캐시 헤더 확인 curl -i "http://localhost:3000/api/stats?username=torvalds" | grep X-Cache # 결과: # X-Cache: MISS (첫 요청) # X-Cache: HIT (두 번째 요청)
캐시 테스트

캐시 새로고침

refresh=1 파라미터로 캐시 무시

?username=torvalds&refresh=1 캐시 새로고침

Rate Limiting

빠르게 40번 요청하면 31번째부터 제한됩니다.

for i in {1..40}; do curl "http://localhost:3000/api/stats?username=torvalds" done # 결과: 31번째부터 "Rate limit exceeded" 메시지

🔧 고급 테스트

⚠️ 로컬 개발 서버 (npm run dev)가 실행 중이어야 합니다.

응답 시간 측정

# macOS/Linux time curl -s "http://localhost:3000/api/stats?username=torvalds" > /dev/null # 예상 결과: # 첫 요청: 300-500ms # 캐시 히트: 50-100ms

응답 헤더 확인

curl -i "http://localhost:3000/api/stats?username=torvalds" # 확인 항목: # - Content-Type: image/svg+xml # - X-Cache: HIT 또는 MISS # - Cache-Control: public, max-age=3600

SVG 파일로 저장

curl "http://localhost:3000/api/stats?username=torvalds" \ -o stats.svg # 파일 확인 open stats.svg # macOS # 또는 firefox stats.svg # Linux

🐛 트러블슈팅

서버가 안 띄워질 때

# 1. 의존성 설치 npm install # 2. .env.local 파일 확인 cat .env.local # 3. 서버 시작 npm run dev

"GITHUB_TOKEN is not set" 에러

.env.local 파일에 GitHub 토큰이 설정되지 않았습니다.

# 1. GitHub에서 토큰 생성 # https://github.com/settings/tokens/new # 2. .env.local 파일 생성 echo "GITHUB_TOKEN=ghp_XXXX" > .env.local # 3. 서버 재시작 npm run dev

포트 3000이 이미 사용 중일 때

# macOS/Linux - 포트 확인 및 종료 lsof -i :3000 kill -9 PID # 또는 다른 포트 사용 PORT=3001 npm run dev
